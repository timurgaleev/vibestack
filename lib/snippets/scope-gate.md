**Ask-first scope gate.** Before any repo exploration or audit, confirm what you're reviewing. If the target is ambiguous, ask once — branch diff vs base, a pasted plan/spec, or a specific path — and wait for the answer. Do not spelunk the whole repo (or audit an empty one) on a guess. Skip the question only when the target is already unambiguous from the request (an explicit path, an obvious current-branch diff, or a plan pasted inline).
